Novità principali della versione 1.7.9

La versione 1.7.9 introduce funzioni pensate per rendere il live più veloce, ordinato e professionale.

🤖 Bruce Assistente IA

Chat integrata che aiuta con player, database, playlist, Jangle, Crea Karaoke, YouTube, Banco Suoni Pro e scalette live.

🎼 Crea Karaoke migliorato

Nuova scelta guidata: Crea Karaoke AI, Crea Karaoke Manuale, Apri/Modifica LRC ed Editor Cori.

🎬 Nuovo Jangle Pad Wall

Interfaccia più moderna, tooltip sui pad, gestione set, anteprima, pad audio, Audio+GIF, testo e foto/slideshow.

🎹 Banco Suoni Pro

Download separato dedicato agli utenti Professional per migliorare la resa dei file MIDI/KAR compatibili.

📚 Database repertorio

Archivio basi con filtri, Base OK, alias cantanti, ricerca più ordinata e gestione file spostati.

🧾 Borderò / log serata

Funzione utile per memorizzare i brani cantati e mantenere uno storico della serata.

🛠️ Nuova scheda Utility

Generatore logo e Convertitore universale per preparare loghi animati, MP3, file audio/video e basi con LRC.

Funzioni principali

🎤 Player karaoke professionale

📚 Database basi karaoke

Archivio con cantanti, titoli, formati, stato, filtri, Base OK, alias e ritrova file.
