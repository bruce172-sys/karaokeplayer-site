CORREZIONE AGGIORNAMENTO AUTOMATICO GITHUB

Questa versione usa uno script sicuro e non nasconde mai il contenuto della pagina.
Se GitHub non risponde, il sito resta visibile con versione e link presenti nell'HTML.
Quando GitHub risponde, vengono aggiornati soltanto:
- numero versione
- data release
- link installer
- changelog

Caricare sul server TUTTI i file dello ZIP, soprattutto:
- index.html
- download.html
- assets/js/latest-release.js

Dopo il caricamento premere CTRL+F5 nel browser.
