AGGIORNAMENTO AUTOMATICO RELEASE GITHUB

File aggiunto: assets/js/latest-release.js
Pagine collegate: index.html e download.html

COME FUNZIONA
1. Pubblica una nuova Release ufficiale nel repository bruce172-sys/VegasKaraokePlayer.
2. Seleziona la release come Latest.
3. Allega un installer EXE con nome simile a VegasKaraokePlayer_Setup_2_3_4.exe.
4. Inserisci le novità nel campo Release notes e premi Publish release.

Il sito aggiorna automaticamente:
- numero versione;
- data di pubblicazione;
- pulsanti download;
- changelog in Home e Download;
- title e meta description visibili al browser;
- softwareVersion nei dati strutturati caricati in pagina.

SICUREZZA E RISERVA
Se GitHub non risponde, rimangono visibili versione e link di riserva 2.3.1.
I dati vengono memorizzati nel browser per 30 minuti per ridurre le richieste API.

IMPORTANTE
Le nuove immagini, le nuove pagine e i testi commerciali specifici delle grandi versioni restano da aggiornare manualmente.
